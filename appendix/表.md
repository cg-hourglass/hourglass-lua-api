# 表

Lua 的 `table` 既是数组也是关联数组，在本引擎的接口里主要有三种用法。

## 数组形 table

一组从 1 开始连续编号的值，用花括号字面量书写，如 `{11, 11, 11, 11, 11}`。多个需要成组传入的同类参数常用这种写法，例如 [Battle.PVE](../battle/PVE.md) 的怪物ID数组与等级数组：

```lua
local TM_EnemyIdAr = {11, 11, 11, 11, 11};
local TM_BaseLevel = {200, 200, 0, 0, 100};
Battle.PVE(TM_PlayPtr, TM_NpcPtr, nil, TM_EnemyIdAr, TM_BaseLevel);
```

引擎按 Lua 的 `#`（数组长度）读取这类参数，只看连续的 `1..n` 部分；超出接口约定容量的元素会被静默截断——例如 Battle.PVE 的怪物队列最多 10 只，多出的部分不会报错，只是不生效。传入非 table 的值通常按空数组或失败处理，具体以各函数页的说明为准。

## `{}` 空表字面量

用于返回值语义是“无内容但类型是 table”的场景，例如 [Debug.Snapshot](../debug/Snapshot.md) 目前固定返回一张空 table。

## 键值对 table（关联数组）

也可以作为字符串/数值键的映射使用，例如 [SQL.Query](../sql/Query.md) 的结果集就是一张以 `"行号_列号"` 字符串为键的 table。这种用法不要求键连续编号，也不参与前面提到的“数组长度”截断规则；某个键不存在时，对它取值得到 `nil`。
