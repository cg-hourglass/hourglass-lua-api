# 说明

Map 库提供了一组对地图进行操作的接口，主要用于生成、复制、查询与修改地图数据。

这个库同时为脚本开放了一个独立的地图 ID 区块：所有通过 `Map.MakeCopyMap` /
`Map.MakeMazeMap` 生成的地图，其 Map ID 固定是常量 `%地图类型_LUAMAP%`，
与角色所在的普通地图、公会房、副本地图等区块是完全独立的命名空间。

这个区块一共只有 128 个 Floor 槽位，由 `Map.MakeCopyMap` 与
`Map.MakeMazeMap` 共享，按"第一个空槽"分配，用完前必须先用 `Map.DelLuaMap`
释放不再使用的地图，否则新的分配请求会失败（返回 -1）。

`Map.MakeMazeMap` 是异步接口：调用本身只做参数校验并预留槽位，真正的房间/
墙壁生成在后台完成，完成后按名字解析并调用脚本里定义的回调函数
（`MakeMazeMapCallBack`）。在回调触发之前，不应该假设该地图已经可以承载
玩家——过早地传送玩家进去，坐标很可能还没有被初始化。

`Map.DelLuaMap` 删除地图时会自动清场：地图上的道具随对象一并删除，玩家会
收到系统提示后被强制传送回登录点，宠物与 NPC 类实体各自走对应的清理流程。

`Map.GetImage` / `Map.SetImage` 是对地图单元格底层（地板）与顶层（物件）
图档的直接读写，系统会根据图档编号所在的区间自动判定它属于地板层还是物件
层；写入会立即广播给该坐标附近的在线玩家。

具体的函数调用方式，请参考本目录的[演示](demo.md)章节，其中给出了 Map 库
全部函数的实际调用示例。函数级别的完整签名、参数与返回值说明见本目录下各
函数页（`Map.MakeCopyMap`、`Map.MakeMazeMap` 等）。
