MakeMazeMap

Map.MakeMazeMap(ScriptFile, CallbackName, XSize, YSize, MapName, Pal, RoomMinSize, RoomXMin, RoomYMin, RoomXMax, RoomYMax, BaseTile, OtherTile, OtherObj, WallH, WallHUp, WallV, WallVUp, WallCross)

函数功能

异步生成一张随机（迷宫）地图；调用立即返回预留的 FloorId，实际生成在后台完成后通过回调函数通知结果。

参数说明

  • ScriptFile: 字符串 回调函数所在的脚本文件；若为字符串会先 dofile 该文件，通常传 nil 表示回调函数已在当前脚本中定义。 [可为空]
  • CallbackName: 字符串 生成完成后触发的回调函数名（按名字解析，见 MakeMazeMapCallBack）。
  • XSize: 数值型 地图 x 坐标范围（宽度上限）。
  • YSize: 数值型 地图 y 坐标范围（高度上限）。
  • MapName: 字符串 地图名，用于地图显示与「地下城正在崩塌」系统提示；超过 31 字节会被截断（按合法字节边界截断，不会切碎多字节字符）。
  • Pal: 数值型 调色板 ID；省略时为 0。 [可为空]
  • RoomMinSize: 数值型 随机地图块的最小大小；省略时为 10，需与后 4 个参数一起提供才会生效。 [可为空]
  • RoomXMin: 数值型 随机地图块 x 坐标最小值；省略时为 15，需与本组其余参数一起提供才会生效。 [可为空]
  • RoomYMin: 数值型 随机地图块 y 坐标最小值；省略时为 15，需与本组其余参数一起提供才会生效。 [可为空]
  • RoomXMax: 数值型 随机地图块 x 坐标最大值；省略时为 15，需与本组其余参数一起提供才会生效。 [可为空]
  • RoomYMax: 数值型 随机地图块 y 坐标最大值；省略时为 15，需与本组其余参数一起提供才会生效。 [可为空]
  • BaseTile: 数值型 地板图档编号；省略时为 7820，需与后 2 个参数一起提供才会生效。 [可为空]
  • OtherTile: 数值型 其他地板图档编号；省略时为 100，需与本组其余参数一起提供才会生效。 [可为空]
  • OtherObj: 数值型 其他物件图档编号；省略时为 0，需与本组其余参数一起提供才会生效。 [可为空]
  • WallH: 数值型 墙横向图档编号；省略时为 17089，必须与下面 4 个参数同时提供才会生效。 [可为空]
  • WallHUp: 数值型 墙横向反向图档编号；省略时为 17088，必须与本组其余参数同时提供才会生效。 [可为空]
  • WallV: 数值型 墙纵向图档编号；省略时为 17089，必须与本组其余参数同时提供才会生效。 [可为空]
  • WallVUp: 数值型 墙纵向反向图档编号；省略时为 17088，必须与本组其余参数同时提供才会生效。 [可为空]
  • WallCross: 数值型 墙相交图档编号；省略时为 17087，必须与本组其余参数同时提供才会生效。 [可为空]

返回值

成功返回预留的新 FloorId（地图尚未真正生成完毕）；失败返回 -1。

MakeMazeMapCallBack(FloorId, Doneflg)

参数说明

  • FloorId: 数值型 生成完成的地图 Floor ID，由引擎传入。
  • Doneflg: 数值型 生成结果，1 表示生成成功，0 表示生成失败。

返回值

返回值被忽略（引擎以 0 个返回值调用该回调）。

参考实例

local LUAMAPID = %地图类型_LUAMAP%;
function makeMazeMap(index, xsiz, ysiz, mapName)
  --Map.MakeMazeMap 参数简要说明
  --[[
    ----------------------------
    回调函数所在文件
    回调函数名
    地图x坐标最大值
    地图y坐标最大值
    地图名
    ---------------------------- 可选参数，定义地图调色板号
    调色板ID
    ---------------------------- 可选参数，定义随机生成地图的一些变量（要么5个全给，要么全不给）
    随机地图块大小
    随机地图块x坐标最小值
    随机地图块y坐标最小值
    随机地图块x坐标最大值
    随机地图块y坐标最大值
    ---------------------------- 可选参数，定义地图图档信息（要么3个全给，要么全不给）
    地图地板图档编号
    地图其他图档编号
    地图其他物件编号
    ---------------------------- 可选参数，定义地图墙面（要么5个全给，要么全不给；只给一部分等于全部不给）
    墙横向图档编号
    墙横向反向图档编号
    墙纵向图档编号
    墙纵向反向图档编号
    墙相交图档编号
    ----------------------------
  --]]
  local newFloorID = Map.MakeMazeMap(nil, "mazeMapDoneCall", xsiz, ysiz, mapName, 0, 30, 30, 30, 30, 30, 9491, 100, 0, 0, 0, 0, 0, 0);
  if (newFloorID == -1) then
    NLG.SystemMessage(index, "地图生成失败。");
  else
    NLG.SystemMessage(index, "地图"..LUAMAPID..","..newFloorID.."已经开始生成了...请稍后");
  end
  return;
end

备注

  1. 五组可变参数是按组生效的：只有当调用参数个数达到该组的右边界 （分别是 6、11、14、19）时，整组才会被读取，否则整组维持默认值； 例如只传到第 16 个参数（提供了墙横向/墙横向反向图档但缺墙纵向/墙纵向 反向/墙相交），不会读取任何一个墙面参数——五个墙面图档全部维持默认 值，这是沿袭旧版的行为，与「按需生效」的直觉不符，参数必须凑满整组 的右边界才会生效。
  2. 墙面参数任一项为 0（而非全部为 0）即会触发自动生成洞穴风格，这点 容易与直觉相反，请留意。
  3. 生成过程是异步的：本函数只预留槽位、校验参数并把生成请求排入后台 队列，真正的房间/墙壁生成完成后才会触发 CallbackName 指定的回调； 回调在完成时刻按名字解析，因此调用之后再定义/重新赋值该全局 函数名仍然有效，但如果完成时刻该名字解析不到函数，这次通知会被 静默丢弃并记录日志。
