StallStart

NLG.StallStart(CharIndex, Name, Msg, Items, Pets)

函数功能

让玩家按给定的价格表开摊，可以同时设置魔币价和代币价（摆摊扩展）。

参数说明

  • CharIndex: 数值型 摊主的对象index，必须是玩家；离线摊主（没有在线连接）也可以。
  • Name: 字符串 摊位名称，最多 16 字节，与原生开摊相同；按服务端运行时编码（Big5 或 GBK）计算，一个中文字算 2 字节。
  • Msg: 字符串 摊位留言，最多 64 字节，计算方式同 Name。
  • Items: 表 道具价格表，键是背包栏位（8~27），值是 {gold = 魔币价, token = 代币价}，两个字段都可省略（按 0 处理），整叠的价格。传 nil 表示不卖道具。 [可为空]
  • Pets: 表 宠物价格表，键是宠物栏位（0~4），值的格式与 Items 相同。传 nil 表示不卖宠物。 [可为空]

返回值

与原生开摊相同的结果码：0 成功；1 同一格已经有别人的摊位；3 距离上次开摊太近（冷却）；4 摊位数量已满；100 其它失败（摆摊未开启、不在允许摆摊的地图、战斗/组队/观战/交易中、已经在摆摊、价格表无效、道具不可上架等）。

参考实例

local sig = NLG.StallStart(player, "小铺", "欢迎光临",
  {[8] = {gold = 500}, [9] = {gold = 100, token = 3}},
  {[0] = {token = 50}});
if sig ~= 0 then
  NLG.SystemMessage(player, "开摊失败：" .. sig);
end

备注

本函数是本服务端新增的接口，C 版 gmsv 没有。 校验与玩家从摆摊窗口开摊完全相同（地图、战斗、队伍、交易、冷却、同格、禁售、上限），另外： - 一个栏位只要魔币价或代币价有一个大于 0 就算上架；两个都为 0 的栏位忽略；全部为 0 时开摊失败。 - 魔币价不能超过角色金钱上限，代币价不能超过配置 stall.token_price_max；负数、栏位越界、键或价格不是数值时开摊失败（原生窗口会静默忽略这类输入）。 - 代币价需要配置 stall.token_price 打开，否则带代币价的价格表开摊失败。 - 与原生一样，价格写在空背包栏位上会被忽略，宠物栏位即使没有宠物也会记下价格。 - 没有安装扩展客户端的玩家只能看到并购买有魔币价的商品；只有代币价的商品对原生摊位窗口隐藏。 - 开摊成功且摊主在线时，服务器会像原生开摊一样给摊主的客户端发送开摊成功的回应（客户端据此显示自己的摊位名）；失败时不发送，由脚本自己提示。
