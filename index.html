hourglass-gmsv Lua 脚本引擎

本文档是 hourglass-gmsv 服务端内置 Lua 5.2.4 脚本引擎的 API 参考手册，面向编写 NPC/事件脚本的开发者。

各库按主题分组：NL/NLG 提供事件注册与通用工具，Char/Battle/Pet/Item/Obj/Map 对应各类游戏对象的读写与操作，Field/Setup/SQL/Protocol/Offline/Debug 则是数据存储、配置、数据库与协议层面的辅助与集成能力。每个函数一页，包含签名、参数说明、返回值与示例；部分函数附带备注，说明需要特别留意的行为细节。完整目录见下方各节；跨函数的通用约定——数值/字符串/布尔/函数/表等参数类型、对象index/道具index/战斗index 等句柄概念、可用的扩展模块——见附录部分。

NL 库

函数 功能简述 别名
NL.Charset 获取当前 gmsv 运行时使用的文本编码。
NL.CreateAccount 异步注册一个游戏帐号，结果通过固定名回调函数返回。
NL.CreateArgNpc 直接创建 data/npc.txt 支持的各种内建类型 NPC，并传入该类型对应的参数。
NL.CreateCharacter 异步在指定帐号的指定栏位创建一个游戏角色，结果通过固定名回调函数返回。
NL.CreateNpc 用 Lua 脚本创建一个 NPC，并执行指定的初始化函数。
NL.DelNpc 删除一个 NPC。
NL.DeleteCharacter 异步删除指定帐号指定栏位的角色，结果通过固定名回调函数返回。
NL.GetErrorStr 获取引擎最近一次记录的错误信息。
NL.RegAfterWarpEvent 注册玩家使用传送点时触发的 Lua 函数，比 RegWarpEvent 多带传送前后的完整坐标。
NL.RegBattleActionEvent 注册玩家在战斗中发出指令时触发的 Lua 函数。
NL.RegBattleExitEvent 注册玩家中途离开战斗时触发的 Lua 函数。
NL.RegBattleGetProfitEvent 注册战斗结算发放奖励时触发的 Lua 函数，可以改写掉落道具或决斗点。
NL.RegBattleNewTurnStartEvent 注册战斗新回合开始时触发的 Lua 函数。
NL.RegBattleNextEnemyEvent 注册通过 Battle.SetNextBattle 设定的连战触发的 Lua 函数，用来提供下一波敌人。
NL.RegBattleOverEvent 注册战斗结束时触发的 Lua 函数。
NL.RegBattlePVPMaxHpEvent 注册 PK 战斗初始化角色最大生命值时触发的 Lua 函数，可以改写该上限。
NL.RegBattleSkillExpEvent 注册对象获得战斗技能经验时触发的 Lua 函数，可以改写实际获得的技能经验。
NL.RegBattleStartEvent 注册战斗开始时触发的 Lua 函数。
NL.RegBattleSurpriseEvent 注册战斗偷袭判定时触发的 Lua 函数，可以改写偷袭结果。
NL.RegCharActionEvent 注册玩家做出动作（晕倒、攻击、剪刀石头布等）时触发的 Lua 函数。
NL.RegDamageCalculateEvent 注册战斗中计算伤害时触发的 Lua 函数，可以改写最终伤害值。
NL.RegDropEvent 注册玩家掉线时触发的 Lua 函数。
NL.RegEquipmentLevelEvent 注册读取装备使用所需等级时触发的 Lua 函数，可以改写该等级要求。
NL.RegFpConsumeEvent 注册消耗魔力值（FP）时触发的 Lua 函数，可以改写消耗量。
NL.RegGetExpEvent 注册对象获得战斗经验时触发的 Lua 函数，可以改写实际获得的经验值。
NL.RegGetLoginPointEvent 注册玩家登入时读取登录点信息触发的 Lua 函数，可用来实现原地登录。
NL.RegGetNextLevelExpEvent 注册读取升到下一级所需经验时触发的 Lua 函数，可以改写经验曲线。
NL.RegHeadCoverEvent 注册生成角色头饰效果时触发的 Lua 函数，可以在不装备头饰道具的前提下指定头饰图档。
NL.RegItemDurabilityChangedEvent 注册道具耐久度变化时触发的 Lua 函数。
NL.RegItemMaxDurabilityChangedEvent 注册道具最大耐久度变化时触发的 Lua 函数。
NL.RegItemOverLapEvent 注册道具栏内把一个道具拖到另一个道具上时触发的 Lua 函数，可以拦截这次移动。
NL.RegItemString 注册一个可以在 itemset 中使用的道具效果字段，道具触发该字段时会调用指定的 Lua 函数。
NL.RegLevelUpEvent 注册玩家角色升级时触发的 Lua 函数。
NL.RegLoginEvent 注册玩家登入游戏时触发的 Lua 函数。
NL.RegLoginGateEvent 注册玩家点击客户端“登出回记录点”时触发的 Lua 函数，可以拦截该操作。
NL.RegLogoutEvent 注册玩家主动登出游戏时触发的 Lua 函数。
NL.RegMakeItemStringEvent 注册生成道具介绍文字时触发的 Lua 函数，可以改写道具说明文本。
NL.RegMergeItemEvent 注册玩家用生产技能制作道具时触发的 Lua 函数。
NL.RegNpcCreatedEvent 注册 NPC 被创建时触发的 Lua 函数。
NL.RegPartyEvent 注册玩家组队与离队时触发的 Lua 函数，可以拦截该操作。
NL.RegPetEquipCheckEvent 注册宠物装备道具前触发的 Lua 函数，可以禁止本次装备。
NL.RegPetLevelUpEvent 注册宠物升级时触发的 Lua 函数。
NL.RegPetRideImageEvent 注册服务器处理骑宠图档时触发的 Lua 函数，可以改写显示的骑宠图档。
NL.RegProductSkillExpEvent 注册对象获得生产技能经验时触发的 Lua 函数，可以改写实际获得的技能经验。
NL.RegRightClickEvent 注册玩家右键点击另一名玩家时触发的 Lua 函数。
NL.RegSealEvent 注册玩家封印宠物时触发的 Lua 函数，可以改写封印结果。
NL.RegShutDownEvent 注册服务器关闭时触发的 Lua 函数。
NL.RegStallTradeEvent 注册摆摊交易时触发的 Lua 函数，可以自行处理金钱结算或直接拒绝交易。
NL.RegTalkEvent 注册玩家说话时触发的 Lua 函数，可用来做自定义指令、GM 命令与聊天过滤。
NL.RegTechOptionEvent 注册读取技能附加参数（TECH_OPTION 字段）时触发的 Lua 函数，可以改写字段值。
NL.RegTitleChangedEvent 注册玩家称号发生变更时触发的 Lua 函数。
NL.RegVSEnemyCreateEvent 注册玩家遇敌生成敌人队列时触发的 Lua 函数，可以改写遇敌队列和数量。
NL.RegWarpEvent 注册玩家被传送到指定坐标时触发的 Lua 函数。
NL.SetArgNpc 修改一个 Lua 创建的 NPC 的参数，并让它按新参数重新初始化。
NL.SetRemoteNpc 设置 NPC 的远程模式，开启后该 NPC 可以不受距离限制被触发。
NL.Ver 获取 Lua 引擎的版本标识。

NLG 库

函数 功能简述 别名
NLG.CanTalk 判断玩家当前是否可以与目标 NPC 交谈（在 CheckTalkRange 的几何判定基础上，额外拒绝不可见/停用的 NPC）。
NLG.CharLook 让对象转向指定方向（只转身，不移动），并触发朝向两格内的对话联动检查。
NLG.CheckInFront 判断目标对象是否位于自身朝向方向、指定距离以内的直线格子上。
NLG.CheckTalkRange 检查两个对象是否处于可对话的位置关系（大致等价于“面对面且相距不超过2格”）。
NLG.DischargeParty 解散指定对象所在的队伍。
NLG.DropPlayer 强制断开指定玩家的连接。
NLG.FindNpcByName 按名字查找 NPC 类对象。
NLG.FindNpcByPos 按坐标查找该格子上的第一个 NPC 类对象。
NLG.FindUser 按帐号（CdKey）查找当前在线玩家的对象index。
NLG.GetFloorPets 获取指定地图楼层上放置在地面的所有宠物对象。
NLG.GetFrontChar 获取对象面前一格内、符合指定类型条件的所有对象数量和对象index列表。
NLG.GetGameTime 获取游戏内当前所处的时段。
NLG.GetIp 获取玩家当前连接的IP地址。
NLG.GetMAC 获取玩家登录时上报的MAC地址（本版本已启用MAC地址限制功能）。
NLG.GetMapName 获取指定地图楼层当前设置的显示名称。
NLG.GetMapPlayer 获取指定地图楼层上所有在线玩家的对象index。
NLG.GetMapPlayerNum 获取指定地图楼层上在线玩家的数量。
NLG.GetMessage 按ID读取旧版 msg.txt 消息表里的一条文字（不是 langmsg 多语言目录）。
NLG.GetOfflineEndTime 同 Offline.GetOfflineEndTime
NLG.GetOfflineStartTime 同 Offline.GetOfflineStartTime
NLG.GetOfflineStatus 同 Offline.GetOfflineStatus
NLG.GetOnLinePlayer 获取当前全服在线玩家总数。 NLG.GetPlayerNum
NLG.GetStallItemPrice 获取玩家摆摊道具的定价表。
NLG.GetStallPetPrice 获取玩家摆摊宠物的定价表。
NLG.GetStallStatus 获取玩家的摆摊状态。
NLG.GetString 以给定分隔符集合切分字符串，取切分结果里第Pos个（从0开始）token。
NLG.MapEffect 清除全服玩家的地图特效，或对指定地图楼层设置地图特效；两种调用方式共用同一个函数名。
NLG.MoveItem 在玩家的物品栏位之间移动/合并道具。
NLG.Rand 生成一个指定范围内（含两端）的随机整数，使用服务器自身的随机数源。
NLG.SendGraphEvent 给对象发送一个白名单内的图形观察事件（如战斗、升级、摆摊等状态图标的显示/隐藏），非玩家对象还会连带更新其内部技能状态。
NLG.SetAction 设置对象当前的动作状态并向周围广播。
NLG.SetHeadIcon 设置对象头顶显示的状态图标（如采集、生产等技能进行中的提示）。
NLG.SetMapName 设置指定地图楼层的显示名称，并向当前在该楼层的所有玩家实时广播。
NLG.SetObj 在指定地图坐标写入一个物件（贴图对象），不改变该坐标的地砖。
NLG.SetOfflinePlayer 同 Offline.SetOfflinePlayer
NLG.SetPal 改变玩家客户端当前显示的地图调色板。
NLG.SetShowName 设置 NPC/宠物/敌人对象是否像玩家一样在头顶显示名字。
NLG.ShowTalked 触发一个对象自身注册的对话模板函数，并把另一个对象当作发起对话的一方传入。
NLG.ShowWindowTalked 生成并向目标对象发送一个对话框封包。
NLG.SortItem 整理玩家的背包物品。
NLG.SystemMessage 给指定对象发送一条黄色加粗的系统公告消息。
NLG.SystemMessageToMap 给指定地图上的所有在线玩家发送一条黄色加粗的系统公告消息。
NLG.Talk 让指定角色通过完整对话管线说一句话——与玩家客户端发出的对话封包走同一入口，会经过对话事件、连坐指令（聊天魔法）等处理，而不是像 TalkToCli 那样直接下发 TK 封包。
NLG.TalkToCli 让一名角色对指定对象（或全服）说话，走直接 TK 封包通道，不经过对话事件/连坐指令解析。 NLG.Say
NLG.TalkToFloor 让一名角色对指定地图+楼层上的所有在线玩家说话，走直接 TK 封包通道。 NLG.TalkToMap、NLG.Say2Map
NLG.Talked 调用引擎内置的银行/窗口治疗师/伤病医生三种 NPC 对话模板之一，是通往这几个legacy系统的桥接函数，不是通用的对话钩子。
NLG.UpChar 强制刷新一个对象的客户端显示状态，视对象类型触发不同的重发流程。
NLG.Update_Party 让指定对象重新向队伍全体成员广播一次队伍参数。 NLG.UpdateParty
NLG.WalkMove 让对象朝指定方向走一格（真实位移，不只是转身）。
NLG.Walkable 检测地图上指定坐标是否可通行。
NLG.WatchBattle 让一名对象进入观战状态，观看另一名对象当前所在的战斗。 NLG.WatchEntry
NLG.WindowTalked Talked 的窗口交互半区，配合内置银行/窗口治疗师/伤病医生对话框的按钮响应使用。
NLG.c 将文本按 46 个半角字符宽度居中补空格，常用于 NPC 对话框标题的居中显示。

Char 库

函数 功能简述 别名
Char.AddGold 为目标对象增减金钱。
Char.AddPet 按敌人模板 ID 为对象制作一只 1 级宠物并加入宠物栏，成长档随机。
Char.AddSkill 为玩家增加指定技能，可同时播种初始经验。
Char.CheckTitle 重新检定玩家的全部称号解锁条件。
Char.ClrClrEvt 批量同时清除对象的 NowEvent 与 EndEvent 任务旗标。
Char.ClrEvtEnd 批量清除对象的 EndEvent 任务旗标。
Char.ClrEvtNow 批量清除对象的 NowEvent 任务旗标。
